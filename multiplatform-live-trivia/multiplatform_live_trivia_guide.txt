MULTIPLATFORM LIVE TRIVIA — USER GUIDE
======================================

This guide is written for running the application on Windows. The project can
be packaged and edited on Arch Linux, but the Windows launcher scripts must be
run on the Windows computer.

1. FIRST-TIME WINDOWS SETUP
---------------------------

1. Extract the project ZIP into a permanent folder, for example:
   Documents\Multiplatform Live Trivia
   Do not move or delete this folder after creating the Desktop shortcut.

2. Install Python 3.12 on Windows and enable the option to add Python to PATH.
   The launcher prefers the Python 3.12 launcher command (py -3.12); if that
   command is unavailable, it uses the default python command on PATH.

3. Open the extracted project folder.

4. Double-click "Create Desktop Shortcut.bat" once. This creates a shortcut
   named "Multiplatform Live Trivia" on your Windows Desktop. You can also run
   "Create Desktop Shortcut.ps1" from PowerShell.

5. Double-click the new Desktop shortcut to start the application. On the
   first launch, the script creates a local .venv and installs the packages
   listed in requirements.txt. An internet connection is needed for this
   first installation. It then starts the server and opens the dashboard in
   your browser. Keep the terminal window open while using the app.

You can also start the app directly by double-clicking "Start Trivia.bat" in
its project folder. The Desktop shortcut is just a convenient way to run that
same launcher.

Dashboard:  http://127.0.0.1:8000
OBS overlay: http://127.0.0.1:8000/overlay

2. DASHBOARD SETTINGS
---------------------

Open the Settings tab in the dashboard.

General
- Question timer: how long viewers have to answer.
- Result duration / transition delay: how long result and transition screens
  are displayed.
- Facebook extra answer time and timestamp tolerance: timing allowances for
  Facebook comments.
- Text-answer attempts and fuzzy matching threshold: controls for text
  answer matching.
- Game timing and matching changes apply to upcoming rounds.

Platforms
- Enable or disable TikTok and Facebook.
- Edit the TikTok username and Facebook session ID.
- The saved Facebook session ID is displayed in the settings page so you can
  review or edit it.
- Saving platform connection settings automatically stops and reconnects the
  relevant platform adapter. You do not need to close the dashboard or restart
  the Python application. Allow the connection a moment to come back online.

IMPORTANT: The Facebook session ID is a private credential. It is stored in
local config.json and is intentionally visible in the local dashboard. Do not
share config.json, publish it, or expose the dashboard to the public internet.
Keep the server bound to 127.0.0.1 unless you have separately secured access.

3. MANAGING QUESTIONS
---------------------

Open Settings, then Questions.

You can:
- Add, edit, delete, and reorder questions.
- Create welcome screens that do not have an answer timer.
- Create multiple-choice questions (MCQ) with options A, B, C, and D.
- Select one or multiple correct MCQ options.
- Create text and supported numeric answer questions.

Use the question editor's Save question list button to save the ordered list
to data/questions.json. Questions can only be saved when the game is waiting
for the host to start the next question. This prevents edits from changing a
question sequence in the middle of an active round or while results are shown.

4. PREPARING A LIVE
-------------------

1. Start the TikTok LIVE and/or Facebook LIVE you intend to use.
2. Open the trivia dashboard and check that the desired platforms show as
   connected.
3. Check that the question list and game settings are correct.
4. In OBS, use a Browser Source pointing to:
   http://127.0.0.1:8000/overlay
5. Keep the trivia terminal window and the required live/platform connections
   running during the game.

For Facebook, continue to follow the connection requirements of the Facebook
adapter and any existing Social Stream Ninja setup used by your installation.
Do not close a required helper window while the Facebook connection depends
on it.

5. RUNNING A GAME
-----------------

1. Make sure at least one intended LIVE platform is connected.
2. Click START ROUND in the dashboard.
3. The current question appears on the dashboard and OBS overlay.
4. Viewers submit answers in the LIVE chat.
5. Correct answers receive points according to the configured matching rules.
6. When the round ends, the results are displayed.
7. Click START ROUND again when ready for the next question.

Repeat until the question list is finished. The leaderboard is updated as the
game runs and saved by the application.

6. SHUTTING DOWN
----------------

1. Finish or stop the live game.
2. Close the dashboard browser tab if desired.
3. In the launcher terminal window, press Ctrl+C to stop the server.
4. You can start it next time using the Desktop shortcut.

Do not launch multiple copies of the application at the same time.

7. ARCH LINUX DEVELOPMENT NOTES
--------------------------------

The Windows .bat and .ps1 files are included in the ZIP while developing on
Arch Linux, but they are intended to run on Windows only.

To run the project on Arch Linux for development/testing:

    python -m venv .venv
    source .venv/bin/activate
    python -m pip install -r requirements.txt
    python main.py

Then open http://127.0.0.1:8000 in a browser. Run tests with:

    python -m pytest -q

Keep real platform credentials out of public repositories and shared ZIPs.
