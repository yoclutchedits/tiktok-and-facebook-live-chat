# Multiplatform LIVE Trivia — Daily User Guide

## 1. Start the Trivia Program

Open the **Multiplatform LIVE Trivia** project folder.

Right-click inside the folder and choose **Open in Terminal**.

Run:

```bash
python main.py
```

Keep this terminal open while using the trivia.

Then open a web browser and go to:

```text
http://127.0.0.1:8000
```

This opens the Trivia Dashboard.

---

## 2. Prepare the LIVE

### TikTok

Start the TikTok LIVE normally.

The trivia program will automatically connect to the TikTok LIVE using the configured account.

### Facebook

Before using Facebook LIVE:

1. Open the saved **Social Stream Ninja** session.
2. Make sure the Facebook LIVE is connected.
3. Keep the Social Stream Ninja Dock open.
4. Do not close the Social Stream Ninja window while the trivia is running.

---

## 3. Check the Dashboard

On the Trivia Dashboard, check that the platforms are connected.

The question and leaderboard will appear on the dashboard.

OBS should already be configured to show:

```text
http://127.0.0.1:8000/overlay
```

Do not change the OBS Browser Source.

---

## 4. Start the Trivia

When everything is ready:

1. Make sure the LIVE is running.
2. Make sure the platforms are connected.
3. Click **START ROUND**.
4. The question appears.
5. Viewers answer in the LIVE chat.
6. Correct answers automatically receive points.
7. When the timer ends, the result is shown.
8. Click **START ROUND** again for the next question.

Repeat until all questions are finished.

---

## 5. Questions

The questions are already prepared in:

```text
data/questions.json
```

For normal daily use, **do not edit this file**.

The person using the program only needs to start the game and run the rounds.

---

## 6. After the Game

When the last question finishes, the final leaderboard is displayed.

The scores are automatically saved.

To finish for the day:

1. Stop the LIVE.
2. Close the Trivia browser page.
3. Stop the program by pressing `Ctrl + C` in the terminal.

The next day, start the program again with:

```bash
python main.py
```

## Important

* Keep the terminal running while Trivia is being used.
* Keep Social Stream Ninja open during Facebook LIVE.
* Do not close or change the project files during a game.
* Do not start `main.py` more than once.
